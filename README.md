# Streakly 🔥

A beautiful, minimal habit tracker focused on building streaks.

Built with **Next.js**, **TypeScript**, and **Tailwind CSS**.

## Features

- ✅ Create habits with custom emoji & color
- 🔥 Daily check-ins with satisfying feedback
- 📊 Current streak & longest streak tracking
- 🗓️ GitHub-style activity heatmap
- 📈 Stats: completion rate, total checks
- 🌙 Dark / light mode
- 💾 LocalStorage persistence (your data never leaves the browser)
- 📱 Fully responsive

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Deploy to Vercel with one click or connect the GitHub repo.
